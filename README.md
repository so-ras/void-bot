# 🤖 ربات مدیریت گروه void

ربات فوق‌حرفه‌ای مدیریت گروه برای تلگرام

## ✨ قابلیت‌ها
- مدیریت کامل اعضا (بن، سیک، سکوت، اخطار)
- سیستم ارتقا به مدیریت و مالکیت
- قفل‌های پیشرفته
- فیلتر کلمات ممنوعه
- سیستم خوش‌آمدگویی
- آمار و اطلاعات کاربران
- بازی‌های تعاملی
- تبدیل به استیکر و گیف
- سیستم نقل قول
- نمایش تاریخ (شمسی، میلادی، قمری)
- سیستم امتیاز و جایزه
- سیستم اشتراک و شارژ
- پنل مدیریت شیشه‌ای

## 🚀 نصب و اجرا
1. توکن را از @BotFather بگیرید
2. آیدی عددی را از @userinfobot بگیرید
3. فایل config.py را ویرایش کنید
4. در Railway مستقر کنید
